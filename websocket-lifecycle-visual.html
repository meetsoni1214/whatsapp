The reliability contract

          
Transport can fail.
The message cannot vanish.

          
WebSocket delivery is immediate when possible. PostgreSQL and the client-generated ID make the same flow correct when the network is not.

        

        
    
          
  1. Authenticate first. No command is accepted before a valid access token establishes connection identity.
    2. 
          
  2. Commit before acknowledge. message.accepted is proof of durable storage, not merely receipt by the gateway.
    3. 
          
  3. Retry the identity. Reuse clientMessageId so a lost acknowledgement cannot create another row.
    4. 
          
  4. Recover from truth. After reconnecting, reload the newest HTTP history instead of trusting that every live event arrived.
