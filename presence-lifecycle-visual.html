The core boundary

                
Online is ephemeral. Last seen is durable.

                

                    The system deliberately refuses to make PostgreSQL answer a
                    question owned by the active process. Each store carries
                    only the state it can represent correctly.
                

                

                    

                        
In-memory connection registry

                        

                            Answers whether at least one authenticated WebSocket
                            exists right now.
                        

                        

                            

                                StoresSocket sets, per-user counts, transition
                                    revisions.
                            

                            

                                ChangesOn authentication, close, heartbeat
                                    termination, and token expiry.
                            

                            

                                LossExpected on restart. With one API instance,
                                    the empty registry correctly means
                                    offline.
                            

                        

                    

                    

                        
PostgreSQL users table

                        

                            Records the most recent durable moment when the
                            final session went away.
                        

                        

                            

                                StoresOne monotonic last_seen_at timestamp per
                                    user.
                            

                            

                                ChangesOnly after the final authenticated
                                    connection closes.
                            

                            

                                RecoveryConversation HTTP responses combine this
                                    timestamp with the live registry.
                            

                        

                    

                

            


            

                
Race protection

                
Async work must not publish yesterday's state.

                

                    

                        
The reconnect race

                        

                            A database update and peer lookup both await I/O.
                            Alice can reconnect while they are running. Every
                            first/final transition receives a revision; the
                            service checks it again immediately before
                            broadcast.
                        

                    

                    

                        

                            rev 1first session connectsonline sent
                        

                        

                            rev 2final session disconnectsI/O starts
                        

                        

                            rev 3reconnect finishes firstonline sent
                        

                        

                            rev 2old offline work resumessuppressed
